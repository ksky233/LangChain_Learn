# Python环境下三者关系
在命令行里执行：

```powershell
python ainvoke_2.py
```

通常会启动一个 **Python 进程**。

在 Windows 任务管理器里看到的那个：

```text
python.exe
```

通常就是一个**进程**，不是线程。

更准确地说：

```text
python.exe 这个可执行程序
    被操作系统启动后
        变成一个正在运行的进程
```

所以：

- `python.exe`：磁盘上的可执行程序，或者任务管理器里显示的进程映像名
- Python 进程：操作系统正在运行的一个程序实例
- `.py` 文件：被这个 Python 进程解释执行的脚本文件

比如你开两个终端分别执行：

```powershell
python ainvoke_1.py
python ainvoke_2.py
```

那通常会有两个独立的 `python.exe` 进程。它们各自有自己的内存空间、变量、解释器状态、事件循环。

可以理解成：

```text
ainvoke_1.py 不是进程
python.exe 执行 ainvoke_1.py 时，产生了一个 Python 进程
```

然后进程里面有什么？

一个进程至少有一个线程，叫主线程。

```text
Python 进程 python.exe
  └─ 主线程
      └─ 执行你的 Python 代码
```

如果你的代码没有手动创建线程，大部分普通 Python 脚本主要就在这个主线程里跑。

当你写：

```python
asyncio.run(main())
```

发生的是：

```text
Python 进程
  └─ 主线程
      └─ 创建事件循环 event loop
          └─ 调度 main() 这个协程
```

所以事件循环不是进程，也不是线程。它是运行在线程里的一个调度器。

关系可以画成这样：

```text
操作系统
  └─ Python 进程：python.exe
      ├─ 内存空间：变量、对象、模块、堆
      ├─ 主线程
      │   └─ event loop
      │       ├─ Task 1：main()
      │       ├─ Task 2：model.ainvoke(...)
      │       └─ Task 3：asyncio.sleep(...)
      └─ 其他线程：如果程序或库额外创建了线程，才会有
```

线程和进程的关系是：

**进程是资源容器，线程是执行单元。**

进程拥有：

- 独立内存空间
- 文件句柄
- 网络连接
- 环境变量
- 当前工作目录
- 加载的模块

线程负责：

- 真正执行代码
- 拥有自己的调用栈
- 共享同一个进程的内存

一个进程里可以有多个线程：

```text
Python 进程
  ├─ 线程 A
  ├─ 线程 B
  └─ 线程 C
```

这些线程共享同一个进程的内存，所以线程之间可以访问同一批 Python 对象，但也因此会有锁、竞争、线程安全问题。

协程又是什么？

协程不是操作系统线程。协程是 Python 语言层面的“可暂停/可恢复的函数”。

```python
async def main():
    ...
```

调用 `main()` 不会立刻执行函数体，而是创建一个协程对象。事件循环把它包装成 Task 后，才会调度它执行。

协程通常运行在某一个线程里的事件循环上：

```text
主线程
  └─ event loop
      ├─ 协程 A
      ├─ 协程 B
      └─ 协程 C
```

这些协程不是同时在 CPU 上跑，而是协作式切换：

- A 跑到 `await`，暂停
- event loop 切到 B
- B 跑到 `await`，暂停
- event loop 切到 C
- 某个网络请求完成了，event loop 再恢复 A

所以你之前的理解可以整理成：

```text
一个 Python 脚本运行时，通常对应一个 Python 进程。
一个 Python 进程里至少有一个线程。
一个线程里可以运行一个事件循环。
一个事件循环里可以调度多个协程任务。
```

但注意两个修正：

1. **不是一个 `.py` 文件天然等于一个进程。**
   
   是你用 `python xxx.py` 启动了一次解释器，操作系统创建了一个进程来运行它。

2. **不是一个 main 函数等于一个线程。**
   
   `main()` 如果是 `async def main()`，它是一个协程，被事件循环调度，通常运行在主线程里。

拿你的 `ainvoke_2.py` 来说，大概是：

```text
你执行：
.venv\Scripts\python.exe "补充学习\异步调用Demos\ainvoke_2.py"

操作系统启动：
Python 进程 python.exe

进程中有：
主线程

主线程执行：
asyncio.run(main())

asyncio.run 创建：
event loop

event loop 调度：
Task 1：main()

main 里执行：
model_task = asyncio.create_task(model.ainvoke(...))

event loop 现在有：
Task 1：main()
Task 2：model.ainvoke(...)

main 继续执行：
await asyncio.sleep(1)

event loop 现在可以切去推进：
Task 2：模型网络请求
```

一句话非常重要：

**进程和线程是操作系统层面的东西；协程和事件循环是 Python/运行时层面的调度机制。**

任务管理器主要看进程和线程；你在任务管理器里一般不会直接看到协程。
